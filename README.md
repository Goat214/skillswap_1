# SkillSwap University Edition (demo MVP)

Fayllar: index.html, style.css, app.js

## VS Code'da ishga tushirish
1. Papkani VS Code'da oching (File > Open Folder).
2. "Live Server" kengaytmasini o'rnating (Ritwick Dey).
3. index.html ustida o'ng tugma > "Open with Live Server".

Yoki index.html faylini brauzerda ikki marta bosib oching.

Ma'lumotlar brauzer localStorage'ida saqlanadi (kalit: ss2). Tozalash: Sozlamalar > "Demoni qayta boshlash".
